# MANIFESTO

KUP is built around a simple question:

> How capable can an intelligence become when it has to prepare locally, work with the evidence available to it, interact with reality, learn from outcomes, and carry those findings into the next experiment?

This is not a question about which model scores highest on a benchmark. It is a question about what a system can do when the easy option — asking a bigger, external intelligence what to do next — is not available at the moment it matters.

## The invariant

> The model may propose. Evidence decides what KUP is allowed to remember as knowledge.

A hypothesis is not knowledge. A plausible-sounding claim is not knowledge. A claim survives into KUP's memory only after a real test — simulated or physical — has produced evidence for it. Nothing is promoted on confidence alone, model self-report, or prose eloquence.

This single sentence is the filter behind every schema, every gate, and every benchmark rule in this project. If a proposed architecture cannot show its evidence trail, it does not get to claim it learned something — no matter how well it explains itself.

## What KUP is not

- KUP is not a finished answer. It is a place to test a question.
- KUP is not a claim that any current architecture — including any built by the maintainers — has solved autonomous research, AGI, farming, or any other grand framing. It has not.
- KUP is not a benchmark you win by being the most articulate. It is won by producing verified, reproducible evidence.

## What KUP is

An open-ended local research project: a protocol, a benchmark, and an invitation. It starts deliberately small — a synthetic environment with exact ground truth — specifically so that research behavior (how a system observes, hypothesizes, tests, and revises) can be measured before anyone trusts the same system with a physical experiment.

It is published now, unfinished, because the invitation matters more than the polish: fork it, challenge the assumptions, bring a better architecture, break the benchmark, improve the benchmark, show evidence. Bring your system. Let reality decide.
