# keys/

Empty skeleton, and likely to stay mostly empty by design. A KEY (an entrant's architecture) does not have to live in this repository at all — see ARCHITECTURE.md and CONTRIBUTING.md. This directory exists only for the KEY *interface definitions* (the abstract contract a KEY must implement per benchmark, e.g. `observe()`/`propose_hypothesis()`/... for `chromatic-universe-v1`), not for any specific entrant's implementation of that interface.
