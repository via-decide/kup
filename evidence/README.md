# evidence/

Empty skeleton. Holds the harness-generated, independently-re-checkable evidence trails referenced by `competitors/*/*.yaml` result records — the actual measurements a claim is based on, not a summary of them. This is what MANIFESTO.md's invariant ("evidence decides what KUP is allowed to remember as knowledge") points at concretely: an entry in `lore/` without a corresponding record here is not a valid claim.
